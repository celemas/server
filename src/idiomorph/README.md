# Idiomorph

[Idiomorph](https://github.com/bigskysoftware/idiomorph) 0.8.0, `dist/idiomorph.esm.js` from the npm package, unmodified. The live reload script loads it from the reload endpoint to morph pages, so live reload needs no network access.

To update it, copy `dist/idiomorph.esm.js` and `LICENSE` from `npm pack idiomorph`.
